Academic method

I installed GnuPG on my Windows computer and generated an OpenPGP key pair. I published my original public key, confirmed my email identity at keys.openpgp.org, and searched for the key on the Ubuntu server. I independently checked Apache HTTP Server 2.4.54's original upstream source signature using GitHub Actions, then created a distinct academic detached signature on the source archive with a replacement student-controlled RSA-4096 key. A second CI verification checked the archive SHA-256 and this personal signature.

This independent GitHub Pages site distributes the reproducible public artifacts and verification instructions. The private development repository contains the workflow and tests. No secret key, passphrase or revocation certificate is provided.

The historical Apache source is distributed strictly as a classroom cryptographic artifact; its author remains the Apache Software Foundation. My academic detached signature is not an upstream Apache release signature, and does not prove that the software is free of vulnerabilities.
